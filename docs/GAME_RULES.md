# GAME_RULES — Plenty 게임 규칙

규칙 버전 1 · 2026-10-28 · 결정: 기획 담당(사용자) / 정리: 개발

이 문서가 `:core`의 기준이다. 숫자는 **플레이 검증 전 가설**이며 `GrowthConfig`·`RewardConfig` 한 곳에서 바꾼다. "임시" 표시 항목은 기획 담당이 확정하면 콘텐츠 데이터만 교체한다.

## 1. 성장 흐름 (확정)

```text
가방의 말랑 ──심기──▶ 화분의 말랑(씨앗 단계) ──XP 20──▶ 새싹 ──XP 100──▶ 성체
                                       └ 이름 앞말 결정      └ 이름 앞말 결정
```

1. 말랑은 **종류가 정해진 채** 가방에 수집된다. 예: "물결연꽃 말랑". 종류는 바뀌지 않는다.
2. 빈 화분에 말랑을 **심으면** 그 화분의 식물(씨앗 단계)이 된다. 재료는 들지 않는다.
3. 식물은 **여정 동반자(최대 3개)**로 출발했을 때만 주행거리 경험치를 받는다.
4. 경험치가 기준을 넘으면 **자동으로** 다음 단계가 된다(별도 확인 없음).
5. 단계가 바뀌는 순간, **그 단계 동안 쌓인 지역 특성 점수**가 가장 높은 특성이 이름 앞말이 된다.
   - 새싹 이름 = 씨앗 단계에서 쌓인 점수로 결정
   - 성체 이름 = 새싹 단계에서 쌓인 점수로 결정 (새싹과 다를 수 있음)
   - 점수가 하나도 없으면(위치를 한 번도 확인 못 함) 앞말 없이 종 이름만 쓴다
6. 지역 특성은 이름 앞말만 바꾼다. 그림은 종류·단계별 원화를 그대로 쓴다.

## 2. 경험치

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 거리 경험치 | 유효 거리 1 km당 동반자 각각 1 XP | 소수 잔여분은 식물별로 저장해 다음 여정에 합산 |
| 일일 상한 | 식물별 거리 XP 하루 최대 50 | 상한에 걸리면 넘친 XP와 그 여정의 소수 잔여분은 버림 |
| 새싹 기준 | 누적 20 XP | |
| 성체 기준 | 누적 100 XP | 성체 이후에도 XP는 쌓이지만 단계 변화 없음 |
| 동반자 | 출발 시 최대 3개 확정 | 정산 전 동반자를 바꿔도 이번 여정 대상은 바뀌지 않음 |

한 여정에서 기준을 넘으면, 기준 전까지의 XP는 이전 단계 점수로, 넘친 XP는 새 단계 점수로 나눠 넣는다.

## 3. 지역 특성 점수

- 여정의 **도착 지역**(경로 B)이 가진 특성에, 그 여정에서 받은 XP만큼 점수를 더한다.
- 도착 위치를 모르거나 오래된 위치뿐이면 거리 XP는 주되 특성 점수는 주지 않는다.
- **재료 보정**: 씨앗·새싹 단계 식물에 재료를 주면, 그 재료에 연결된 특성에 재료 1개당 **5점**을 더한다. 성체에는 줄 수 없다(이름이 이미 정해짐).
- 동점이면 콘텐츠의 특성 목록 순서가 앞선 특성이 이긴다.

## 4. 지역 보상

| 항목 | 값 |
| --- | --- |
| 지역 재료 | 유효 방문 시 그 지역 재료 1개 |
| 같은 지역 | 하루 1회만 보상 |
| 말랑 | 그 지역 첫 유효 방문은 말랑 1개 보장, 이후 방문은 30% 확률 |
| 말랑 종류 | 전체 종류에서 균등 추첨 (임시) |

추첨 결과는 보상 키와 함께 한 번 확정해 저장하고, 다시 정산해도 다시 뽑지 않는다(T05).

## 5. 유효 거리

누적 주행거리(km) 스냅샷 두 개의 차이로 계산한다(`API_FACTS.md`: Odometer 단위 km).

| 상황 | 처리 |
| --- | --- |
| 시작·끝 값 정상, 차이 0 이상 | 유효 거리 = 차이 |
| 값을 읽지 못함 | **미확인**. 0 km로 확정하지 않고 나중에 다시 정산 |
| 끝 < 시작 (리셋·출처 변경) | **무효**. 보상 없이 새 기준값 설정 |
| 차이 > 2,000 km | **무효** (오류로 간주, 가설값) |

## 6. 콘텐츠 — 임시 (기획 확정 대기)

**지역 특성**: 기획 담당이 종류·앞말·연결 재료를 정의한다. 그 전까지 아래 3가지를 쓴다.

| ID | 이름 앞말 (임시) | 대표 지역 (예) | 보정 재료 (임시) |
| --- | --- | --- | --- |
| `waterside` | 물가의 | 바다·호수·강가 | 달빛이슬 |
| `highland` | 산자락의 | 산간·고원 | 바람돌 |
| `city` | 도시의 | 도심 | 구름빛 |

표시 예: "물가의 구름고사리 새싹", "산자락의 구름고사리" (이름 조합 형식도 기획 확정 대상)

**지역 5곳 (임시)**: 강릉(물가), 부산(물가), 평창(산자락), 서울(도시), 대전(도시). 실제 판정 범위는 T10에서 FusedLocation 영역으로 정의한다.

**종류**: 달빛종(`moonbell`), 구름고사리(`cloud-fern`), 물결연꽃(`tide-lotus`) — 디자인 키트 원화.

## 7. 디자인과 달라지는 점

- 11 "말랑 깨우기 · 재료 사용": 재료 없이 **심기**로 바뀜. 화면 문구·비용 표시 수정 필요.
- 12 "진화 분기 선택 · 재료별 모습": 자동 성장으로 바뀌어 선택 화면이 아니라 **특성 보정**(재료를 주고 예상 이름을 보는) 화면으로 재활용.
- 10 식물 상세의 "진화 선택" 버튼 → "재료로 보정" 등으로 변경 필요.
- 달빛종 별빛형 원화: 지역 특성이 그림을 바꾸지 않기로 했으므로 **현재 사용처 없음**. 특별 보상 등 쓰임은 기획 결정 대기.
