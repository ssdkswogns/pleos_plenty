## 적용 범위

- 10/11/12/13/15는 이전 같은 번호의 화면을 대체합니다. 05/06/08/09의 레벨·지역·지급 문구도 이 버전으로 교체합니다.
- 14 가방 카드의 “깨우기”는 **“심기”**, 재료 설명은 **“○○ 특성을 가꿔요”**로 바꿉니다. 말랑 카드는 11, 재료 카드는 14a로 연결합니다.
- 도감 목록은 **종 이름**을 제목으로 쓰고, 가장 많이 자란 개체의 단계·XP를 아랫줄에 표시합니다. 앞말이 붙은 개체 이름은 15a에서 보여 줍니다.
- 숫자(37 XP, 12점, 보유 4개 등)는 시안 데이터입니다. 실제 값과 임계치는 `GrowthConfig`/저장소를 사용합니다.
- 상세 화면에서 주행 제한 또는 미확인 신호가 오면 표시·입력·모션을 멈춥니다. 플랫폼 차단 화면을 우선합니다.

## 파일 사용

아이콘은 24×24, `fill="none"`, `stroke="currentColor"`, 선 굵기 1.7, round cap/join입니다. 기존 SVG→VectorDrawable 변환에 넣을 소스는 **assets/icons**입니다. 배지 SVG는 텍스트가 있는 합성 디자인 견본입니다. 앱에서는 Icon+Text+Container로 구현하세요.

화면 SVG의 텍스트는 편집 가능하고 식물만 래스터입니다. SVG를 옮길 때 `assets/plant-atlas.png` 상대 경로도 유지하세요. 한글 폰트는 앱과 같은 Noto Sans KR입니다. PNG는 글꼴 설치 없이 검토할 수 있습니다. 1440×900은 논리 디자인 좌표로, 전체 화면을 비트맵처럼 축소하는 구현은 하지 않습니다.

작은 창에서는 좌우 패널을 세로로 쌓고 본문을 스크롤합니다. 뒤로가기·제목과 하단 실행 영역을 유지하고 터치 타깃은 최소 56dp로 지킵니다. 재료 설명은 좁은 창에서 전체 높이 시트가 됩니다. 세로 전용 원화는 이 변경분에 포함하지 않습니다.
