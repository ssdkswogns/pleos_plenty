# 콘텐츠와 기획 결정 — Plenty MVP

2026-10-28. 요청된 미결정 사항의 구현 기준입니다. 엔진의 기존 수치·정산은 변경하지 않습니다.

## 1. 특성은 세 가지로 시작

| 순서 | ID | 표시명 | 이름 앞말 | 연결 재료 / ID | 아이콘 |
|---|---|---|---|---|---|
| 0 | waterside | 물가 | 물가의 | 달빛이슬 / moon-dew | trait-waterside.svg |
| 1 | highland | 산자락 | 산자락의 | 바람돌 / wind-stone | trait-highland.svg |
| 2 | city | 도시 | 도시의 | 구름빛 / cloud-light | trait-city.svg |

특성은 **지역의 분위기를 표현하는 게임 분류**입니다. 점수는 능력치나 희귀도, 성장 속도를 뜻하지 않습니다. 세 특성 모두 종에 관계없이 이름 앞말만 바꿉니다. 동점 우선순위는 `물가 → 산자락 → 도시`로 기존 콘텐츠 순서와 동일합니다. 배지의 순서도 고정합니다. 전부 0점이면 앞말 없음이며 “무특성”이라는 네 번째 특성을 만들지 않습니다.

재료 1개는 해당 특성에 5점, XP 변화 없음. 현재 단계의 점수만 보정합니다. 성장 순간 점수로 다음 이름을 확정한 뒤 점수는 초기화됩니다. 성체는 재료 사용 불가, XP는 계속 쌓입니다. UI의 “예상 이름”은 **지금 점수로 다음 단계가 된다면 나오는 이름**이며, 성장까지 남은 XP가 특정 지역에 쌓일 것을 예측한 결과가 아닙니다.

## 2. 이름 형식

| 상태 | 형식 | 예 |
|---|---|---|
| 가방/화분의 씨앗 | 종 이름 + ` 말랑` | 달빛종 말랑 |
| 새싹 / 앞말 있음 | 앞말 + 공백 + 종 이름 + ` 새싹` | 물가의 달빛종 새싹 |
| 새싹 / 앞말 없음 | 종 이름 + ` 새싹` | 달빛종 새싹 |
| 성체 / 앞말 있음 | 앞말 + 공백 + 종 이름 | 산자락의 달빛종 |
| 성체 / 앞말 없음 | 종 이름 | 달빛종 |

현재 이름은 저장된 `sproutPrefix`/`maturePrefix`에서 가져옵니다. 현재 점수로 이름을 매 프레임 다시 붙이면 안 됩니다. 재료 사용은 예상 이름만 바꾸고 현재 이름은 유지합니다. UI 단계 표시는 `말랑 · 새싹 · 성체`, 내부 enum은 기존 `SEED · SPROUT · MATURE` 그대로 사용합니다.

## 3. 지역 목록

| ID | 표시명 | 게임 특성 | 지급 재료 |
|---|---|---|---|
| gangneung | 강릉 | 물가 | 달빛이슬 |
| busan | 부산 | 물가 | 달빛이슬 |
| pyeongchang | 평창 | 산자락 | 바람돌 |
| seoul | 서울 | 도시 | 구름빛 |
| daejeon | 대전 | 도시 | 구름빛 |

**MVP 지원 지역은 위 다섯 곳으로 고정**합니다. 실제 해안선·산책로·개별 도로를 추적하지 않고, 도착 지점이 속한 지역으로 분류합니다. ‘부산은 물가’는 도시 전체를 게임상 하나로 묶은 콘텐츠 설정이며, 그 지점이 실제 수변이라는 주장은 아닙니다.

판정 단위: 강릉시, 부산광역시, 평창군, 서울특별시, 대전광역시의 행정 영역. T10의 지역 판정기는 검증된 행정 영역 데이터 또는 정규화한 행정 주소를 위 ID에 매핑합니다. 문자열 부분 일치, 중심점과 가장 가까운 도시, 임의 반경으로 다른 지역을 강제 분류하지 않습니다. 행정 경계와 위치 정확도로 유일하게 판정할 수 없으면 unknown입니다. 전국 모든 장소가 이 다섯 지역 중 하나에 속하는 것으로 취급하지 않습니다.

영역 밖은 “지원 지역 밖”, 위치 없음/오래됨/경계 불확실은 “도착 지역 미확인”입니다. 둘 다 지역 ID를 null로 정산하여 지역 점수·재료·말랑은 없고, 유효 거리 XP는 줍니다. 매칭용 경계 데이터, 라이선스, 위치 신선도·정확도 구현 검증은 T10에서 수행해야 합니다. 이 파일은 런타임 지오펜스 데이터가 아니며 좌표를 임의로 확정하지 않습니다. 지역 콘텐츠 ID는 유지해야 기존 지역별 보상 원장이 이어집니다.

## 4. 도감 카드와 만남

- 카드 제목: 종 이름. 아랫줄: `말랑 · 7 / 20 XP`, `새싹 · 37 / 100 XP`, `성체 · 누적 128 XP`.
- XP와 그림의 대표 개체: 같은 종 중 단계가 가장 높고, 그중 누적 XP가 가장 큰 개체. 같으면 plantId가 작은 것. 현재 데이터만으로 구현 가능합니다.
- 누적 XP 막대는 기존 구현처럼 씨앗 `xp / 20`, 새싹 `xp / 100`, 성체 1.0입니다. 새싹 단계 내 비율 `(xp-20)/80`로 바꾸지 않습니다. 라벨과 값이 일치해야 합니다.
- 획득 지역, 레벨, ‘이름 2 / 8’ 표시는 사용하지 않습니다. 씨앗을 얻은 지역을 새로 저장하는 작업도 MVP에 추가하지 않습니다. 여정 결과의 **도착 지역**은 여정 저장 정보로 표시할 수 있으나 씨앗의 영구 출생지로 옮기지 않습니다.
- **만난 식물 = 한 번 이상 화분에 심은 종**. 가방에 말랑만 있으면 미발견으로 유지합니다. 미발견 카드는 잠금과 “말랑을 심어 첫 만남을 기록해요”만 표시하며 종 상세로 이동하지 않습니다.
- MVP에는 식물 삭제/방출이 없어 기존 plants 조회로 충족합니다. 추후 삭제가 생기면 첫 심기 시 `discoveredSpecies` 영구 기록을 추가하여 해금이 되돌아가지 않게 합니다. 현재 구현에 없는 영구 도감 테이블이 이미 있다고 가정하지 않습니다.

## 5. 앞말 수집 여부

**MVP에는 별도 수집하지 않습니다.** 같은 종의 앞말마다 도감 칸을 늘리거나 수집 완료율을 표시하지 않습니다. 다음 개발은 여정과 차량 연동에 집중합니다. 종 상세에는 대표 개체의 현재 이름과 단계만 표시합니다.

향후 별도 기능으로 도입할 때에만 `speciesId × traitId`를 새싹 또는 성체로 실제 성장한 순간에 영구 해금합니다. 예상 이름, 재료 사용 미리보기, 단순 보유로는 해금하지 않습니다. 그때 분모는 3특성이고 무접두 이름은 기본 이름으로 둡니다. 이 항목은 후속 확장 방향이며 이번 구현 요구나 데이터 마이그레이션이 아닙니다.

## 6. 변경하지 않는 규칙

여정 동반자 1~3개, 거리 1km당 각각 1 XP, 개체별 일일 최대 50 XP, 20/100 누적 XP에서 자동 성장, 재료 1개당 5점, 지역별 하루 1회 보상, 첫 유효 방문 말랑 보장·이후 30%는 기존 설정을 유지합니다. 숫자는 계속 플레이 검증 전 가설이며 화면에 상수를 복제하지 않습니다. 말랑 3종은 moonbell/달빛종, cloud-fern/구름고사리, tide-lotus/물결연꽃입니다.
